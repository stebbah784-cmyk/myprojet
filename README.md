Analyse des sentiments liés à la COVID-19

 Description:

Projet de Machine Learning visant à analyser et classifier les sentiments exprimés dans des tweets liés à la COVID-19.

Le projet utilise des techniques de traitement du langage naturel (NLP) ainsi qu'un modèle de Machine Learning entraîné pour prédire le sentiment des textes.
 
 Technologies utilisées:

- Python
- Pandas
- Scikit-learn
- TextBlob
- Streamlit
- Plotly

Fichiers du projet:

- "app.py" — Application web Streamlit
- "project.py" — Traitement des données et code Machine Learning
- "model.pkl" — Modèle de Machine Learning entraîné
- "vectorizer.pkl" — Vectoriseur utilisé pour le traitement du texte
- "requirements.txt" — Bibliothèques nécessaires

 Objectif:

L'objectif de ce projet est d'appliquer des techniques de Machine Learning et de NLP pour analyser les sentiments présents dans des textes liés à la COVID-19.
